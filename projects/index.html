AI Lead Intake & Support Triage Automation

I designed and built a multi-scenario Make.com automation that captures leads and support requests from a web form and email through custom webhooks, then uses the OpenAI API to classify intent, urgency, and sentiment into structured JSON.

Make.comOpenAI APIAirtableGmailGoogle SheetsWebhooksJSON
My contribution

I built the routers and filters that send each record to an Airtable CRM (contacts, tickets, status), a duplicate check by email lookup, Gmail alerts for high-priority cases, AI-drafted replies held for human approval, plus error-handler routes, retries, input validation, and a Google Sheets run log.

What I learned

I learned to make AI output dependable inside a workflow: force structured JSON, validate it, route on it, and keep a person in the loop before anything is sent.

AI Job Hunting Agent

I built a set of Make.com scenarios that read job-alert emails, score each job against my verified profile with Gemini, log it to a Google Sheets job CRM, and draft a tailored resume and cover letter for my review. It never submits applications on its own.

Make.comGemini APIGoogle SheetsGmailStructured AI output
My contribution

I planned and built five scenarios (job intake and scoring, resume drafts, recruiter-email monitor, call-outcome processing, follow-up reminders) and an error-log scenario, with approval gates and rules that stop the AI from inventing experience.

What I learned

I learned to split one big automation into small scenarios that share a data store, and to write prompts with hard truthfulness rules. It has been tested with synthetic data; real job alerts are next.

Cortex

I built an on-phone AI coding agent that runs open models (Qwen2.5 Coder, Llama 3.2) locally with llama.cpp. It has a ChatGPT-style chat, file tools that ask before writing, memory and skills, LoRA add-ons, a 3D knowledge graph, and optional web search or cloud AI when you turn them on.

KotlinJetpack Composellama.cppGGUFLoRAAndroid
My contribution

I integrated the native llama.cpp engine, the in-app model downloader with checksum checks, the agent loop and tools with approve-before-write diffs, the chat UI, and the knowledge graph. v0.2.0 is released as an APK.

What I learned

I learned what it takes to run a language model on a phone: model size, memory limits, and keeping a small model on task with tight tool rules.
